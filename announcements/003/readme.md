# 喵ingTab 1.3.4 版本更新

## 版本定位

`1.3.4` 版本是一个重要的过渡版本，也是连接过往版本与即将发布的 `2.0.0` 的桥梁，基于此，`1.3.4` 是不可跳过的版本。

## 功能变更

- 为了便于后续小组件的扩展与新增，`添加小组件` 功能在 `1.3.4` 中升级为独立的 `小组件中心`
- `基础设置` 新增 `界面风格` 设置，当前支持 `默认`、`卡通`、`液态风格` 三种设置，该功能尚未完全打磨，将在 `2.0.0` 版本进行充分优化
- `壁纸设置` 新增 `视差壁纸` 分类页签，`视差壁纸` 是一次探索性实现，后续大概率不会频繁更新

## 深层变化

- `1.3.4` 移除了原有的外部视觉组件并重新构建了一套基础视觉组件，在当前版本中，它还存在一些不足，这些不足会在 `2.0.0` 版本中进行更进一步的组织和优化
- `喵ingTab` 尽管在早期设计时就已充分考虑了底层的数据基座，但也无法得知今天 `1.3.4` 的模样——`喵ingTab` 目前有 `1300+` 文件，`24w+` 行代码，去掉注释后约为 `17w` 行，排除掉测试、配置等基础依赖等内容，依旧有 `700+` 文件和 `10w+（不包含注释）` 的代码，这其中涉及的功能、兼容以及功能背后看不见的支撑已经到了一定量级，在功能和组织层面的推动下，`1.3.4` 重新构建了数据存储、备份等一系列底层支撑，`1.3.4` 以前的版本升级到 `1.3.4` 后所有迁移变更会静默进行
- 与数据存储、备份一同更新的还有数据加密，在 `1.3.4` 之前的版本中，您的重要的数据虽已加密，但并非完全不可解密；`1.3.4` 重新设计了一套严格的数据加密与恢复体系，并保证即使发生意外（如插件数据彻底损坏，浏览器数据被清除，系统重装等），您依然能够找回数据——`数据管理` 菜单中新增的 `找回数据` 正是为此准备（前提是必须有通过备份数据保存的备份文件）。`找回数据` 依赖在线托管服务，但传递内容仅包含必要的密钥信息交换，您的备份数据始终只保存在您自己的终端上，如果在线托管服务异常，您也可以在 `数据管理` 菜单通过连续按 `3` 次 `Q` 键触发手动找回流程，之后按提示操作即可，此方式无法即刻找回数据，流程较在线找回也更复杂一些。

## 写在最后

如前面所说，`1.3.4` 是衔接过往版本和 `2.0.0` 版本的桥，`1.3.4` 发布后，`喵ingTab` 会留出充足的时间，等待您升级到该版本，直到合适的时机再发布 `2.0.0` ，`2.0.0` 将不再兼容 `1.3.4` 之前的版本。届时，`喵ingTab` 会卸下历史包袱，以更加从容、更加完善的姿态和所有用户见面。

希望您能喜欢 `喵ingTab 1.3.4` 带来的变化，同时您也可以与我们共同期待 `2.0.0` 的到来。

发布日期：2026-10-24
